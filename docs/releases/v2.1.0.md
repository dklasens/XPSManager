# XPS Manager v2.1.0

## What's new

- **ExpressCharge for 24 hours:** get a full charge for a day out, then automatically return to Primarily AC Use. See the return time or choose **Return now** to end early. The saved timer works with the app closed and survives restarts.
- **Version number in the app:** find it discreetly beside the BIOS version.
- **Windows installer:** install the app, Start menu shortcut, required .NET runtime and background service together. Future MSI updates keep your automatic settings.
- **Clearer layout:** separate Settings, Automatic and Activity tabs, with improvements to BIOS validation and background-service reliability.

## Download and install

Download **XpsManager-2.1.0-win-x64.zip**, extract it and run the MSI inside. The standalone MSI is also available. Windows 11 x64 and administrator access are required; no separate .NET installation is needed.

For an existing portable installation, first record your automatic settings and remove its background service from the downloaded app's **Automatic** tab. Then install the MSI. Existing MSI users can run the new installer to upgrade.

## Things to know

- Developed for the Dell XPS 14 DA14260. Other models are unverified, and the charging timer requires BIOS support for ExpressCharge and Primarily AC Use.
- This release is unsigned. Windows may display an unknown-publisher or SmartScreen warning. SHA-256 checksums are supplied with the downloads.
- The return timer is checked every 30 seconds. If Windows is asleep or shut down at expiry, restoration runs after resume/startup. Use **Return now** before uninstalling.
- Automated timer, BIOS and installer checks run in GitHub Actions. A live 24-hour cycle and some hardware sleep/restart cases remain unverified; see the repository's validation notes.
